# 固件

三个 APP 可以并存于 Flash，长按 KEY 约 2 秒后松开，按槽位顺序切换。上电时按住 KEY 进入 IAP，可在其中选择启动槽或烧写镜像。

## 文件

| 文件 | 槽位 | 烧录地址 | 说明 |
|---|---|---|---|
| `SLOT0_CH32H417_Logic_Analyzer_APP_v0.2.bin` | 0 | `0x08006000` | 逻辑分析仪，当前版本 |
| `SLOT1_CH32H417_USB2UART_DAP_APP.bin` | 1 | `0x08052000` | USB 转串口 + DAP |
| `SLOT1_CH32H417_USB2UART_DAP_APP_fix_keil5.36.bin` | 1 | `0x08052000` | 同上，USB 产品名改为 WeAct Studio CMSIS-DAP，供 Keil 5.36 识别 |
| `SLOT2_CH32H417_Example_APP.bin` | 2 | `0x0809E000` | 教学示例，单路 CDC 打印工程信息 |
| `dll_fix_keil.zip` | — | — | Keil 5.36 识别 DAP 所需的 DLL，覆盖到 Keil 安装目录的 `ARM\BIN` |

## 逻辑分析仪版本

版本号由 `0xAC` 应答中的 `sw` 字节给出：`0x01` 为 v0.1，`0x02` 为 v0.2。v0.1 镜像保留在 `legacy version/`，需要回退时使用。

v0.2 相对 v0.1 的变化：

- 指示灯亮度可由上位机设置，分暗 / 默认 / 较亮 / 亮 / 最亮五档。
- 按键短按次数在「读取采集参数」（`0xA4`）的应答中上报，供上位机实现按键开始 / 停止采集。
- 加入 Microsoft OS 1.0 兼容描述符（WCID）。Windows 默认使用 CH375 驱动；需要改用 WinUSB 时，在设备管理器中卸载设备并勾选「删除此设备的驱动程序软件」，重新插拔后固件 0.2 自动绑定 WinUSB。v0.1 没有兼容描述符，改用 WinUSB 仍需 Zadig。

指示灯亮度与按键启停两项需要上位机 0.2.0.0 或更高版本。

## 烧录

在上位机中选择「帮助 → 固件升级」，按提示选取镜像与目标槽。

现场同时接有多块板时，命令行烧录必须用 `-d` 指定目标板的完整 SN。不带该参数时工具会选中匹配到的第一块板。烧录前先用 `--dry-run` 确认写入范围。
